# Документация проекта

Здесь лежат документы, которые помогают развивать проект, но не участвуют в runtime-сборке.

## Точки входа

- [`../README.md`](../README.md) — запуск, окружение и команды.
- [`../DEVELOPMENT_BACKLOG.md`](../DEVELOPMENT_BACKLOG.md) — порядок продуктовой разработки и Definition of Done.
- [`../DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md) — визуальные токены, карта экранов и правила UI.
- [`../DESIGN_FILE_MAP.md`](../DESIGN_FILE_MAP.md) — краткая памятка по файлам дизайна.
- [`PROJECT_STRUCTURE.md`](PROJECT_STRUCTURE.md) — логическая карта репозитория и правила размещения новых файлов.

## Куда добавлять новые материалы

- `docs/` — продуктовые, технические и дизайн-документы.
- `attached_assets/` — только входные материалы и референсы, полученные извне.
- корень — только обязательные файлы проекта: `README.md`, `package.json`, конфигурация workspace и скрипт запуска.

Документы в корне, на которые уже ссылаются README или инструменты, пока остаются там для удобного доступа и обратной совместимости ссылок.
