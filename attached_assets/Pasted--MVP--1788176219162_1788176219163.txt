До открытия письма:

- таймер задания не отображается;
- таймер не идет.

При первом открытии:
- сохранить task1StartedAt;

таймер задания продолжает идти.

После refresh рассчитывать оставшееся время через task1StartedAt, а не запускать новые 7 минут.

# 17. AIRTABLE — РЕГИСТРАЦИЯ УЧАСТНИКОВ

Регистрации должны сохраняться в Airtable.

НЕ отправлять запросы в Airtable напрямую из React.

Создай backend endpoint:

POST /api/register

Frontend отправляет:

{
  firstName,
  lastName,
  age,
  email,
  consent
}

Backend:
1. валидирует данные;
2. создает participantId через UUID;
3. добавляет registeredAt;
4. записывает участника в Airtable;
5. возвращает participantId.

В Airtable сохранять:

- participantId
- firstName
- lastName
- age
- email
- consent
- registeredAt

Используй Replit Secrets:

AIRTABLE_TOKEN
AIRTABLE_BASE_ID
AIRTABLE_TABLE_NAME

Airtable token НЕ должен попадать:
- во frontend;
- в localStorage;
- в публичный код.
